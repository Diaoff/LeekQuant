## 1. 首次使用

### 1.1 启动服务

```bash
docker compose up -d
```

首次启动会自动创建数据库、执行迁移、seed 初始数据。等待约 30 秒后访问 http://localhost:8080。

### 1.2 同步数据

1. 进入 **数据同步** (`/status`) 页面
2. 点击 **同步股票基础信息** — 拉取全市场 5000+ 股票
3. 点击 **同步交易日历** — 导入 A 股交易日历
4. 点击 **同步日K线** — 增量拉取历史K线（首次可能需要较长时间）

> 建议首次使用同步最近 1-2 年数据即可，后台定时任务会自动补充历史数据。

### 1.3 配置数据源

进入 **偏好设置** (`/preferences`) 页面 → **数据源** 选项卡：

- AData（Tier 1）：默认启用，推荐作为主源
- Baostock（Tier 2）：默认启用，K线备源
- AkShare（Tier 3）：默认启用，兜底源

可以拖拽调整优先级顺序，关闭不需要的数据源。

### 2.1 筛选股票

**股票市场** (`/market`) 页面支持多维筛选：

| 筛选条件 | 说明 |

| 市场 | 主板 / 创业板 / 科创板 / 北交所 |

## 4. 策略编写

### 4.1 编辑器

**策略** (`/strategy`) 页面使用 Monaco Editor（VS Code 内核）提供：

- Python 语法高亮
- MyTT 函数自动补全（输入 `MA`、`MACD`、`KDJ` 等自动提示）
- 实时语法检查
- 多版本管理

### 4.2 策略模板

```python
def generate_signal(ctx):
    close = ctx.close("000001.SZ")
    ma5 = MA(close, 5)
    ma20 = MA(close, 20)

    if CROSS(ma5, ma20)[-1]:
        return {"signal": "买入", "reason": "MA5金叉MA20"}
    if CROSS(ma20, ma5)[-1]:
        return {"signal": "卖出", "reason": "MA5死叉MA20"}

    return {"signal": "观望", "reason": "无信号"}
```

### 4.3 ctx 上下文 API

| 方法 | 返回 | 说明 |
|------|------|------|
| `ctx.close(code)` | numpy array | 收盘价序列 |
| `ctx.high(code)` | numpy array | 最高价序列 |
| `ctx.low(code)` | numpy array | 最低价序列 |
| `ctx.open(code)` | numpy array | 开盘价序列 |
| `ctx.volume(code)` | numpy array | 成交量序列 |
| `ctx.ts_codes` | list | 股票池列表 |

> 详细策略编写指南见 [strategy-guide.md](strategy-guide.md)。

## 5. 回测

### 5.1 创建回测

1. 在 **策略** 页面选择策略
2. 配置回测参数：
   - **初始资金**：默认 1,000,000
   - **回测区间**：起止日期
   - **股票池**：全体A股 / 自选股分组 / 自定义
   - **滑点**：默认 0.1%
   - **止损/止盈**：可选，百分比
3. 点击 **开始回测**，提交异步任务

### 5.2 查看结果

回测完成后可以查看：

- **性能指标**：总收益、年化收益、夏普比率、最大回撤、胜率等
- **净值曲线**：与基准（沪深300）对比
- **交易记录**：完整买卖明细、费用分项（佣金/印花税/过户费）
- **月度收益**：逐月收益分布
- **信号日志**：每次信号触发记录

### 5.3 多策略对比

在回测列表勾选多个策略，点击 **对比** 查看：

- 净值曲线叠加对比
- 指标横向对比表
- 月度收益热力图
- 多策略相关性

## 6. 五档信号

### 6.1 信号定义

| 信号 | 语义 | 空仓 | 轻仓 | 半仓 | 重仓 |
|------|------|------|------|------|------|
| 买入 | 强烈看多 | BUY→100% | 加至目标 | 加至目标 | HOLD |
| 增持 | 温和看多 | BUY→50% | 加25% | HOLD | HOLD |
| 减仓 | 降低风险 | HOLD | HOLD | 减25% | 减25% |
| 卖出 | 清仓离场 | HOLD | 全卖 | 全卖 | 全卖 |
| 观望 | 维持现状 | HOLD | HOLD | HOLD | HOLD |

### 6.2 信号日志

- 按股票筛选
- 按信号类型筛选
- 按日期范围筛选
- 导出 CSV

## 7. 模拟交易

### 7.1 创建账户

**模拟交易** (`/simulation`) 页面 → **新建账户**：

| 参数 | 说明 |
|------|------|
| 账户名称 | 自定义名称 |
| 初始资金 | 默认 1,000,000 |
| 交易费率 | 使用偏好设置中的默认费率 |

### 7.2 交易功能

- **委托下单**：支持限价/市价/收盘价三种模式
- **持仓管理**：查看当前持仓、可用股数(T+1冻结)
- **成交记录**：完整费用明细
- **资金流水**：出入账记录
- **净值曲线**：累计净值、最大回撤

### 7.3 A股规则限制

- **T+1**：当日买入次日9:25自动解锁
- **涨跌停**：涨停不可买、跌停不可卖
- **最小交易单位**：100股（1手）
- **停牌处理**：停牌期间无法交易

### 7.4 实时风控

`realtime_risk_guard` 后台服务监控模拟持仓：

- 止盈：达到目标收益率自动挂单卖出
- 止损：达到最大亏损率自动挂单卖出
- 配置：在偏好设置中调整止盈止损参数

## 10. 常见问题

### 数据不显示？

1. 检查 **数据同步** 页面是否有未完成的任务
2. 确保 Postgres 和 Redis 服务正常运行：`docker compose ps`
3. 查看日志：`docker compose logs backend`

### 回测结果为 0？

1. 检查策略是否正确导入了 MyTT
2. 确认股票池不为空
3. 检查回测区间是否有交易日
4. 查看策略执行日志中的错误信息

### 如何重置所有数据？

```bash
docker compose down -v   # 删除数据卷（会丢失所有数据）
docker compose up -d     # 重新创建
```

### 如何修改交易费率？

进入 **偏好设置** → **交易费用** 选项卡，调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 佣金费率 | 万2.5 | `0.00025` |
| 最低佣金 | 5元 | 单笔最低 |
| 印花税率 | 0.05% | 卖出收取 |
| 过户费率 | 万0.1 | `0.00001` |
| 免最低佣金 | 否 | 封闭式基金等特殊品种 |

# Fix: DashboardPage blank due to API response format change

## Root Cause

The backtest list API (`GET /api/backtests`) was changed from returning `BacktestResult[]` to `{items: BacktestResult[], total: number}` (pagination). But `DashboardPage.tsx` still expects a flat array at line 98/107:

```tsx
fetchJson<BacktestSummary[]>('/api/backtests?limit=5')
// ...
setRecentBacktests(backtestsResult.value) // value is now {items, total}
```

Then at line 174:
```tsx
recentBacktests.length === 0  // objects don't have .length → undefined
recentBacktests.map(...)       // objects don't have .map() → CRASH
```

This crashes the entire React tree, rendering a blank page.

## Fix

**File**: `frontend/src/pages/DashboardPage.tsx`

1. Update the API call to handle the new paginated response format:
```tsx
const raw = await fetchJson<{ items: BacktestSummary[]; total: number } | BacktestSummary[]>('/api/backtests?limit=5')
const backtests = Array.isArray(raw) ? raw : (raw.items ?? [])
setRecentBacktests(backtests)
```

2. Or more simply, just extract `.items` if it exists:
```tsx
if (backtestsResult.status === 'fulfilled') {
  const raw = backtestsResult.value
  setRecentBacktests(Array.isArray(raw) ? raw : (raw.items ?? []))
}
```

## Verification

1. `cd frontend && npx vite build` — should succeed
2. Open homepage — should show dashboard with recent backtests
3. Check that BacktestPage still works with pagination
